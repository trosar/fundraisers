# Scout Fundraisers

This repository hosts the Troop 60 scout fundraiser websites.

## Stores

- **`ms/`** — Meat Sticks & Chocolate Fundraiser
- **`fs/`** — Plant Sales Fundraiser

## Deployment

Deploy on Railway with a single service. Set environment variables with `MS_` and `FS_` prefixes:

```
MS_DB_HOST=...
MS_DB_PORT=...
MS_DB_NAME=...
MS_DB_USER=...
MS_DB_PASS=...
MS_DB_TAB_PREFIX=ms_2026
MS_ADMIN_PASS=...
MS_STORE_IS_PROD=true
MS_STORE_IS_OPEN=true
MS_GTAG_VERSION=...

FS_DB_HOST=...
FS_DB_PORT=...
FS_DB_NAME=...
FS_DB_USER=...
FS_DB_PASS=...
FS_DB_TAB_PREFIX=ps_2026
FS_ADMIN_PASS=...
FS_STORE_IS_PROD=false
FS_STORE_IS_OPEN=true
```

## Local Development

Each store reads its own `.env` file from its directory:

- `ms/.env` — Meat Sticks & Chocolate config
- `fs/.env` — Plant Sales config
